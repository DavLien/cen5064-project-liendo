# ADR-003: Hybrid Native tk.Canvas and Pillow Pipeline for Real-Time Stopwatch Feature

**Date:** 2026-10-23 | **Status:** Accepted

## Context

Tracking live play sessions requires a responsive stopwatch with a smooth orbiting progress indicator, crisp circular controls, and dynamic window scaling. Standard CustomTkinter widgets rely on widget-level redraws that stutter at 50 Hz refresh intervals and cannot render anti-aliased circular geometry or sub-second precision cleanly. Additionally, storing session durations only as rounded hours caused short sessions under one minute to lose precision in total playtime calculations.

## Decision

We will render the session stopwatch stage on a single native `tk.Canvas` backed by pre-rendered, supersampled Pillow (`PIL`) sprites that scale with fast bilinear interpolation during active resizing and crisp Lanczos resampling on settle. In the Data tier (`SqliteSessionRepository`), we will persist exact sub-second durations in a `duration_seconds` column via safe `PRAGMA` auto-migration alongside `duration_hours`.

## Consequences

The stopwatch maintains smooth 20 ms frame updates and proportional resizing without widget churn, while total playtime aggregates exact recorded seconds across all sessions. This introduces Pillow (`PIL`) as a runtime imaging dependency (with a vector canvas fallback if unavailable) and requires maintaining sprite-caching logic inside `presentation/gui.py`.
